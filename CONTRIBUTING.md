# Contributing to SoulLife

Thank you for your interest in contributing to SoulLife.

## How to Contribute

1. Fork the repository
2. Create a new branch for your feature or fix
3. Make your changes in the `common/` module when possible
4. Test your changes on at least one loader (NeoForge, Fabric, or Forge)
5. Submit a pull request with a clear description of what you changed

## Code Style

- Use 4-space indentation
- Keep platform-specific code in the loader modules
- Keep shared logic in `common/`
- Add comments for complex logic
- Follow existing naming conventions

## Reporting Bugs

Please open a GitHub Issue with:
- Minecraft version
- Mod loader and version
- Description of the bug
- Steps to reproduce
- Any relevant error logs

## Suggesting Features

Open a GitHub Issue labeled `enhancement` with a clear description of the feature and why it would improve the mod.
